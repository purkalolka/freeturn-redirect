# freeturn-redirect

Telegram-бот + сайт-переходник на `freeturn://`-ссылки. Без базы данных:
ссылки живут в памяти процесса (+ best-effort `links.json`), после
перезагрузки/передеплоя пропадают — так задумано.

## Как это работает

Владелец шлёт боту готовую `freeturn://...` ссылку, бот валидирует её
(base64url JSON, `v == 1`, обязательны `provider` и `peer`) и отвечает
короткой страницей:

```
https://<домен>/r/a7k2x9
```

Страница `/r/<code>` — кнопка + JS-переход на `freeturn://...`.
В приложении FreeTurn открывается шит импорта (подтверждение + VK-ссылка
на звонок, если её нет в самой ссылке).

Запасной вариант без хранения: `/go?link=freeturn://...` — ссылка прямо
в URL, переживает любой рестарт, но URL длинный.

## Страницы

- `/` — тёмный лендинг по макету Penpot: заголовок IBM Plex Mono и
  размытое свечение-эллипс снизу. Свечение голубое (`#61b4ff`), пока
  `/health` отвечает, и оранжевое (`#ff7f00`), если проверка упала;
  мерцает медленно, как свеча. На десктопе (≥1200px) слева сверху —
  белое меню с быстрыми ссылками `/health` и `/bot` (username бота
  подтягивается из `BOT_TOKEN` через `getMe`) и вращающимся ASCII-донатом
  в сером frame. На мобильных меню скрыто
- `/r/<code>` — карточка с кнопкой и автопереходом на `freeturn://`
- `/go?link=...` — то же без хранения
- `/health` — JSON `{"ok": true}` для healthcheck

Шрифты лежат в `static/` и отдаются с долгим кэшем: IBM Plex Mono и
Source Code Pro на главной, Inter на остальных страницах. Тёмная тема
карточек включается автоматически по `prefers-color-scheme`. OG-теги
нейтральные — имя профиля в превью ссылки не попадает.

## Команды бота

- `/new` — прислать ссылку
- `/list` — живые ссылки
- `/del <code>` — удалить
- `/delall` — удалить все

## Env

| Var | Назначение |
|---|---|
| `BOT_TOKEN` | токен нового бота из @BotFather (не @pilolo_robot) |
| `OWNER_TG_ID` | Telegram user id владельца, только он может создавать ссылки |
| `BASE_URL` | публичный URL сервиса, например `https://http--freeturn-redirect--xxx.code.run` |
| `PORT` | по умолчанию `8080` |
| `DATA_FILE` | по умолчанию `links.json` |

## Локальный запуск

```bash
BOT_TOKEN=... OWNER_TG_ID=... BASE_URL=http://localhost:8080 PORT=8080 python3 app.py
# без BOT_TOKEN работает только сайт
curl localhost:8080/health
```
